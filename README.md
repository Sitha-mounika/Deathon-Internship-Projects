# Deathon Internship Projects

Welcome to my **Deathon Internship Projects** repository! This repository contains Python projects developed during my internship to strengthen my programming, problem-solving, and practical development skills.

## 🚀 Projects

### Task 1: Hangman Word Guessing Game
A console-based word guessing game developed using Python.

**Features**
- Random word selection.
- Letter-by-letter guessing.
- Maximum of 6 incorrect attempts.
- Tracks previously guessed letters.
- Validates user input and prevents duplicate guesses.
- Displays win or lose messages.
- Supports a `words.txt` word list.

**Run the project**
```bash
python hangman.py
```

### Task 2: Stock Portfolio Performance Tracker
A Python application that calculates stock investment performance using prices entered by the user.

**Features**
- Accepts stock ticker symbols.
- Records buy prices and share quantities.
- Accepts current prices manually.
- Calculates investment and current portfolio values.
- Calculates profit or loss and percentage.
- Saves portfolio summaries to a CSV file.

**Run the project**
```bash
python portfolio.py
```

*Note: This version uses manually entered prices and does not fetch live stock prices.*

### Task 3: File Organizer
A Python program that organizes files into folders based on their extensions.

**Features**
- Automatically identifies file types.
- Organizes images, documents, videos, audio, Python files, and ZIP files.
- Creates category folders automatically.
- Places unrecognized file types in an `Others` folder.
- Skips duplicate destination filenames to avoid overwriting files.
- Uses a test folder to help protect files in your main folders.

**Run the project**
```bash
python file_organizer.py
```
