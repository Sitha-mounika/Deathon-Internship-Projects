# Deathon Internship Projects

Welcome to my Python Internship Projects repository! This repository contains Python projects developed as part of my internship program to improve my programming, problem-solving, and file-handling skills.

## 📌 Projects

### Task 1: Hangman Word Guessing Game

A beginner-friendly, console-based word guessing game developed using Python.

**Features**
- Random word selection.
- Letter-by-letter guessing.
- Maximum of 6 incorrect attempts.
- Tracks previously guessed letters.
- Validates user input and prevents duplicate guesses.
- Displays win or lose messages.
- Supports loading words from `words.txt` (if implemented in the code).

**How to Run**
```bash
python hangman.py
```

### Task 2: Stock Portfolio Performance Tracker

A Python application that calculates the performance of stock holdings based on user-provided stock prices.

**Features**
- Accepts stock ticker symbols.
- Records buy prices and share quantities.
- Accepts current prices entered by the user.
- Calculates investment value and current portfolio value.
- Calculates profit or loss for each holding.
- Calculates profit or loss percentage.
- Saves portfolio summaries to a CSV file.

**How to Run**
```bash
python portfolio.py
```

The portfolio tracker uses manually entered prices; live market prices are not fetched automatically.
