# 🎮 Hangman Word Guessing Game

## 📌 Project Overview
Hangman is a simple word-guessing game developed using Python. The player tries to guess a hidden word one letter at a time before running out of attempts.

## ✨ Features
- Random word selection
- Letter-by-letter guessing
- Maximum of 6 incorrect attempts
- Displays guessed letters
- Input validation
- Win and lose messages
- Supports loading words from a `words.txt` file

## 🛠️ Technologies Used
- Python
- Random module
- File handling
- Sets and conditional statements
- Loops and functions

## 🚀 How to Run

1. Install Python on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/Sitha-mounika/hangman-game.git
   ```

3. Open the project folder:

   ```bash
   cd hangman-game
   ```

4. Run the game:

   ```bash
   python hangman.py
   ```
